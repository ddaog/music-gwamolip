# 문장의 파장 — formyiru playground 001

한글·영어 단문을 단어의 정서와 심상에 따라 Strudel 패턴으로 번역하고, 음악 구조를 부드러운 디지털 기하로 시각화하는 웹 실험입니다.

## 실행

```bash
npm install
npm run dev
```

문장 입력창을 눌러 편집을 시작하면 오디오가 자동으로 깨어나고, 수정하는 문장에 맞춰 Strudel 패턴이 이어서 갱신됩니다. 재생 버튼은 필요할 때 소리를 멈추거나 다시 시작하는 용도로 남겨 두었습니다.

## Vercel 배포

GitHub 저장소를 Vercel에 연결한 뒤 프레임워크는 Vite, 빌드 명령은 `npm run build`, 출력 디렉터리는 `dist`로 설정합니다. 서버 함수나 환경 변수 없이 정적 사이트로 배포할 수 있습니다.

## 번역 원칙

- 35개 심상군에 속한 1,000개 이상의 한·영 표제/어근을 온도, 움직임, 빛, 여백, 부드러움, 긴장의 음악 축으로 변환합니다.
- 물의 청록 잔물결, 빛의 금빛 섬광, 숲의 녹색 유기 곡선, 도시의 자홍·청색 격자처럼 단어별 색·도형·효과를 함께 합성합니다.
- 입력 중인 문장은 단어별 의미색과 질감으로 바로 표시되고, 원경과 근경은 각각 bass 및 topline EQ 응답으로 시각화합니다.
- 사전에 없는 단어도 한글 모음의 인상 또는 영어 철자 리듬과 안정적인 문자열 해시를 통해 고유 음정, 색, 움직임에 기여합니다.
- 시적 장면의 원경(환경·공간)은 pad/bass로, 근경(몸·감정·움직임)은 melody/top line으로 배치합니다.
- 같은 문장과 같은 `우연` 번호는 같은 결과를 만듭니다.
- 사용자 문장은 서버로 전송하거나 저장하지 않습니다.
- 생성 코드에는 사용자 입력 원문을 직접 삽입하지 않습니다.

## 기술 및 라이선스

- Vite
