# 문장의 파장 — formyiru playground 001

문장 간 연결은 모듈러 신스의 GATE·PITCH·LFO 패치로도 동작합니다. 코드의 `PATCH`와 `M1`, `M2`로 신호 방향과 문장 보이스를 확인할 수 있습니다. 실제 동작과 한계는 [문장 패치 신스](./docs/modular-patch.md)를 참고하세요.

한글·영어 단문을 단어의 정서와 심상에 따라 Strudel 패턴으로 번역하고, 음악 구조를 부드러운 디지털 기하로 시각화하는 웹 실험입니다.

## 실행

```bash
npm install
npm run dev
```

문장을 입력하면 오디오가 시작되고, 수정한 문장에 맞춰 패턴이 갱신됩니다. 빈 입력창은 무음이며 한국어 조합 중에는 재생 패턴 갱신을 잠시 미룹니다.

BEAT의 `자동`은 단어 수에 따라 드럼을 더하며, `켜기`는 한 단어에도 킥·스네어·하이햇을 추가합니다. `끄기`는 드럼을 제거합니다. 강도 슬라이더는 드럼 음량만 조절합니다. 접힌 ‘이렇게 해보세요’ 가이드의 예문을 눌러 비교할 수 있습니다.

입력창 아래에는 실제 재생 코드의 `stack`과 음표·리듬 패턴만 표시하며, `.scale`, `.s`, 필터·엔벌로프·음량 등의 설정 체인은 숨깁니다. ‘전체 코드’에서 원본을 확인할 수 있습니다. 한 단어는 선율, 두 단어는 화음, 세 단어는 베이스, 여섯 단어는 보조 선율을 더하며 표시되는 레이어 수도 실제 연주와 함께 늘어납니다. 원경·근경 곡선은 문장의 특성 변화에 부드럽게 반응합니다. 한국어 활용형과 연결절, 영어 동사 변형을 규칙 기반으로 처리하고, 서술어가 아직 없는 미완성 문장은 점선으로 잠정 연결합니다.

긴 글은 입력창과 색상 레이어의 글자 크기를 함께 줄입니다. 데스크톱은 최대 32px에서 24px까지, 모바일은 22px에서 최소 18px까지 줄이며 줄바꿈도 밀도 계산에 포함합니다.

한글 조합 중에도 기존 단어의 색과 연결선을 유지하며, 음악 갱신은 조합 완료 후 적용합니다. Enter는 행갈이로 취급해 이어지는 문장의 주어·술어를 연결하고, 같은 주어가 반복되면 첫 주어에서 여러 대상에 분기선을 추가합니다. 연결절에서는 앞의 명시된 주어를 다음 서술어에도 연결합니다. 새로운 주어나 문장 종결 부호에서는 계승을 멈추며, ‘생각이 난다고 했는데’ 같은 인용절은 내부 주어와 바깥 주어를 구분하는 제한적인 규칙으로 처리합니다. 일반적인 대명사 지시 대상이나 모든 생략 주어를 추론하는 분석기는 아닙니다.

데스크톱은 입력 아래 코드·cycle을 나란히, 모바일은 짧게 쌓아 보여줍니다. 모바일의 가시 영역이 줄면 압축 배치로 전환합니다. 비트·예문·가이드는 접힌 설정에서 열 수 있습니다. 정지는 실제 Strudel 스케줄러와 예약 갱신을 멈추며, 다시 재생을 누르기 전까지 타이핑만으로 재시작하지 않습니다.

단어 연결은 문장 구간별 한국어·영어 규칙으로 추정합니다. 형용사·소유격은 뒤의 명사에, 부사는 가까운 서술어에 연결하며 완전한 형태소·구문 분석기는 아닙니다. 음악은 첫 단어를 으뜸음 기준으로 삼고, 네 마디의 공통 화음 진행 위에 멜로디와 베이스를 놓습니다. 문장 어느 위치든 두려움·분노·슬픔이 인식되면 단조를 사용하며, 두려움·분노는 화음 진행과 선율의 음색·어택·여운에도 영향을 줍니다. `안 무서워`, `무섭지 않아`, `not afraid` 같은 인접 부정은 제외하지만 복잡한 부정문·반어는 완전히 해석하지 못합니다.

비트는 첫 단어와 변주 번호로 네 가지 기본 그루브 중 하나를 고릅니다. 16분음표 단위의 8마디 패턴으로 하이햇 강약과 4·8마디 끝의 추가 타격을 생성합니다. 단어가 늘면 기존 핵심 타격을 유지한 채 세부 타격이 늘고, 8마디 이후 반복합니다. EQ 화면은 의미 기반 시각화이며 실제 오디오 주파수 측정값은 아닙니다.

## Vercel 배포

의미 벡터 확장은 첫 방문에 백그라운드에서 준비한 뒤 자동으로 켜집니다. 첫 사용 시 약 118MB의 다국어 모델과 실행 파일을 내려받으며 입력 문장은 서버로 보내지 않습니다. 데이터 절약·2G 연결에서는 수동 시작을 기다립니다. 입력창 아래 버튼에서 준비 상태와 실제 확장된 단어·연결 수를 확인하고 끌 수 있습니다. 끄기 설정은 다음 방문에도 유지됩니다. 코사인 유사도로 미등록 단어의 심상과 유사어 연결을 보완합니다. 반복 단어 연결은 기본 모드에서도 작동하고, 연결 관계는 리듬 및 응답 선율에 반영됩니다. 범위·한계·캐시 동작은 [의미 엔진 설명](./docs/semantic-engine.md)을 참고하세요.

GitHub 저장소를 Vercel에 연결한 뒤 프레임워크는 Vite, 빌드 명령은 `npm run build`, 출력 디렉터리는 `dist`로 설정합니다. 서버 함수나 환경 변수 없이 정적 사이트로 배포할 수 있습니다.

## 번역 원칙

- 40개 심상군에 속한 한국어 2,182개 고유 표제·어근·활용형(심상군별 등록 2,226개), 영어 715개 등록 항목을 온도, 움직임, 빛, 여백, 부드러움, 긴장의 음악 축으로 변환합니다. 사전은 심상 연상용이며 사전적 정의나 학습된 임베딩이 아닙니다.
- 물의 청록 잔물결, 빛의 금빛 섬광, 숲의 녹색 유기 곡선, 도시의 자홍·청색 격자처럼 단어별 색·도형·효과를 함께 합성합니다.
- 입력 중인 문장은 단어별 의미색과 질감으로 바로 표시되고, 원경과 근경은 각각 bass 및 topline EQ 응답으로 시각화합니다.
- 사전에 없는 단어도 한글 모음의 인상 또는 영어 철자 리듬과 안정적인 문자열 해시를 통해 고유 음정, 색, 움직임에 기여합니다.
- 시적 장면의 원경(환경·공간)은 pad/bass로, 근경(몸·감정·움직임)은 melody/top line으로 배치합니다.
- 같은 문장과 같은 `우연` 번호는 같은 결과를 만듭니다.
- 사용자 문장은 서버로 전송하거나 저장하지 않습니다.
- 생성 코드에는 사용자 입력 원문을 직접 삽입하지 않습니다.
