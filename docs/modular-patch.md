# 문장 패치 신스

문장은 최대 8개의 신스 보이스 모듈로 해석합니다. 문장 경계는 기존 구문 분석기의 마침표·물음표·느낌표 및 문법상 경계가 되는 줄바꿈을 따릅니다. 시의 모든 줄바꿈을 독립 모듈로 자르지는 않습니다.

각 모듈의 기본 오디오 경로는 `VCO → VCF → VCA/envelope → mixer`입니다. 원경 화음·베이스·비트는 기존 공통 버스로 유지됩니다. 두 문장 이상이면 기존 주선율 대신 문장별 보이스가 연주됩니다. 코드의 M1, M2 등이 입력 순서의 문장입니다.

| 연결 | 실제 동작 |
| --- | --- |
| 반복어: GATE → ENV | 앞 문장의 8스텝 게이트 패턴이 뒤 문장의 발음 시점을 대신 결정합니다. 매 발음마다 뒤 모듈의 엔벌로프가 시작됩니다. |
| 공유 주어: SEQ → PITCH | 앞 문장의 음계도 시퀀스를 뒤 모듈이 받아 공통 화음에 양자화된 음높이로 연주합니다. |
| 유사어·그 밖의 문장 간 관계: LFO → VCF | 앞 문장의 움직임이 정하는 2/4/8사이클 사인 신호가 뒤 모듈의 필터를 기준값 ±32%로 변조합니다. |
| 기본 내부 연결: LFO → VCF · NORMAL | 명시적 필터 패치가 없는 문장은 직전 문장의 LFO를 ±16%로 받습니다. 명시적 연결이 생기면 대체됩니다. |

각 입력에는 하나의 소스만 연결합니다. 여러 후보는 본문 분석 순서상 첫 연결을 채택하고 한 출력의 여러 입력 분기는 허용합니다. 신호는 앞 문장→뒤 문장으로만 흐르며 피드백 루프는 만들지 않습니다. 정규화된 믹서 게인으로 문장이 늘 때의 음량을 제한합니다. UI 케이블과 컴파일러는 같은 패치 데이터를 사용합니다. 문장 내부의 기존 문법선은 모듈 간 패치와 구분됩니다.

이것은 모듈러의 **신호 흐름을 차용한 Strudel 패턴 신스**입니다. 아날로그 전압이나 1V/oct를 물리적으로 시뮬레이션하지 않습니다. GATE/PITCH는 시퀀스 데이터를 라우팅하며, LFO는 Strudel signal로 이벤트 시점에 평가됩니다. 오디오 레이트 FM, 실제 모듈 간 오디오 출력 라우팅, 자유로운 케이블 편집은 아직 지원하지 않습니다. 그림만 연결하고 임의로 음악을 바꾸는 구조가 아니라 실제 대상 패턴·필터 입력을 바꿉니다.

검증: 패치 제거 시 대상 필터만 변경, GATE/PITCH 소스 시퀀스 전달, 입력당 한 소스, 순방향 연결, 모듈 상한, UI 코드와 컴파일 결과 일치 회귀 테스트.

원리 참고: [Doepfer A-100 신호 구분](https://doepfer.de/a100_man/a100t_e.htm), [Strudel signal](https://strudel.cc/learn/signals/), [Strudel 필터 변조](https://strudel.cc/workshop/first-effects/).
