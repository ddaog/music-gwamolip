# 음악과몰입

공간과몰입의 소리 방명록. `textusic`의 `0fe53a5` 버전에서 독립 저장소로 분리했습니다.

방문자의 문장과 음악 코드는 해당 사이트 주소의 같은 브라우저에 로컬 저장합니다. 다른 컴퓨터나 브라우저로 자동 동기화되지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료 시 유실될 수 있으므로 주기적으로 백업하세요.

## 사용

1. 문장을 쓰고 음악을 들어봅니다.
2. ‘이 문장 남기기’를 누르고 이름(선택)을 적어 저장합니다. 이름·문장·원본 코드·해석 스냅샷·비트·변주 설정·작성 시각을 IndexedDB에 함께 저장합니다.
3. ‘남겨진 문장들’을 열면 음악을 멈추지 않고 갤러리를 볼 수 있습니다. 열기·닫기·새로 읽기는 오디오 엔진을 재생성하지 않습니다. 다른 작품의 ‘불러와 듣기’를 누를 때만 연주를 변경합니다.
4. ‘새 방명록 쓰기’는 현재 연주를 멈추고 입력을 비웁니다. 저장된 원본은 지우지 않습니다.

작품을 불러오면 저장 당시 해석을 유지합니다. AI 준비 완료로 저장 작품의 코드가 바뀌지 않으며, 문장·비트·변주 등을 직접 수정하면 새 해석으로 전환됩니다. 수정 후 저장해도 이전 작품을 덮어쓰지 않고 별도 작품으로 남깁니다.

## 운영

- 공개 인터넷 갤러리가 아니라 **이 기기의 로컬 컬렉션**입니다. 같은 브라우저라도 다른 도메인·포트·프로필은 별도 저장 공간입니다. 서점에서는 고정 주소와 일반 브라우저 프로필을 사용하세요.
- 갤러리 하단 ‘전체 백업 만들기 → 백업 파일 저장’으로 JSON 파일을 내려받습니다. 현재 버전에는 백업 가져오기 UI가 없으므로 주소 이전·브라우저 초기화 전에 운영자에게 복구 작업을 요청하세요.
- 저장 공간 오류는 사용자에게 표시하고 입력은 남겨둡니다. 서버로 방명록을 보내지 않습니다. 저장 확인창에서 다른 방문자가 볼 수 있음을 안내합니다.
- 저장 코드를 그대로 실행하지 않고 현재 컴파일러로 같은 코드를 생성할 수 있는 스냅샷만 재생합니다. 엔진 업데이트로 코드가 달라진 옛 작품은 표시·백업만 가능하며 마이그레이션이 필요할 수 있습니다.
- 본 저장소는 비공개로 생성했고 아직 호스팅하지 않았습니다. 독립서점 운영 용도의 호스팅 이용 조건은 별도 확인이 필요합니다.
