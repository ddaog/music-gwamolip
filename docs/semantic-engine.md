# 기기 내 의미 확장

`비트 · 가이드 → 의미 확장 · 기기 내 AI`를 켜면 다국어 의미 임베딩을 사용합니다. 기본값은 꺼짐입니다. 반복어 연결과 그에 따른 응답 선율은 모델 없이도 동작합니다.

## 모델과 데이터

- Transformers.js로 `Xenova/paraphrase-multilingual-MiniLM-L12-v2`의 q8 ONNX 모델을 실행합니다.
- 재현성을 위해 모델 리비전을 `2c4055b12046f11709e9df2c122e59ffbdc2f900`으로 고정합니다.
- 모델 본체는 약 118MB입니다. 토크나이저와 WASM 실행 파일도 최초 사용 시 내려받습니다. 실제 전송량은 압축·캐시 여부에 따라 달라집니다.
- 모델 파일만 Hugging Face에서 다운로드하며, 입력 문장·단어·벡터는 원격 추론 API로 전송하지 않습니다. 모델은 브라우저 캐시를 사용하고 사용자 단어 결과는 Worker 메모리에만 최대 512개 보관합니다.
- 스위치를 끄면 Worker와 그 메모리를 종료합니다. 브라우저의 모델 파일 캐시는 남을 수 있습니다.

## 의미를 음악으로

1. 입력 중에는 기존 사전과 구문 규칙으로 즉시 반응합니다.
2. 650ms 입력 휴지 후 별도 Worker에서 단어당 정규화된 mean-pooled 벡터를 계산합니다.
3. 40개 심상군마다 한국어·영어 대표 단어를 각각 4개씩 벡터화합니다. 언어별 기준 벡터 평균을 빼서 단순히 같은 언어라는 이유로 높아지는 유사도를 줄인 뒤 코사인 유사도를 비교합니다. 사전이 인식한 단어의 의미는 덮어쓰지 않습니다.
4. 미등록 단어는 유사도 0.65 이상이고 최고 점수에서 0.065 이내인 최대 3개 심상을 가중 혼합합니다. 감정 심상은 0.68 이상의 더 보수적인 기준을 사용합니다. 1위와 5위 차이가 0.035 미만이면 불명확한 결과로 거절합니다.
5. 온도·움직임·빛·공간·부드러움·긴장의 양극 표현과 비교해 미등록 단어의 음악 축을 제한적으로 보정합니다.
6. `안 무서워`, `무섭지 않아`, `not afraid` 같은 인접 부정은 감정 사전·심상 적용에서 제외합니다. 복잡한 부정문, 반어, 다의어 문맥을 완전히 해석하는 것은 아닙니다.

유사도 수치는 확률이 아닙니다. 기준값은 보수적인 초기 설정이며 폭넓은 한국어 평가 데이터로 보정할 여지가 있습니다. 벡터 입력은 현재 단어 단위이므로 동음이의어를 문맥으로 구별하지 못할 수 있습니다. 한 요청은 고유 단어 최대 48개로 제한합니다.

## 관계선과 음악

- 품사에 상관없이 반복 단어를 연결합니다. 사전에 있는 기본형과 일부 조사·영어 복수형을 정규화합니다.
- 의미 확장이 켜져 있으면 단어 사이 코사인 유사도 0.72 이상인 쌍을 옅은 점선으로 연결합니다.
- 의미·반복 연결은 최대 24개, 단어당 최대 4개입니다. 확정된 문법선과 겹치는 선은 중복 생성하지 않습니다.
- 전체 관계 밀도는 비트의 세부 타격에 영향을 줍니다. 반복·유사어·공유 주어 연결 중 최대 4개는 같은 조성의 질문·응답 선율을 생성합니다. 응답 선율의 음량은 고정된 작은 상한을 유지합니다.
- 오래된 추론 결과는 입력 리비전으로 폐기합니다. 한국어 조합 중에는 추론 결과 적용을 미룹니다. Worker 오류나 3분 초과 시 기본 사전 모드로 돌아갑니다.
- 초기 다운로드 또는 모델 준비 중에도 입력과 기본 음악은 사용할 수 있습니다. 연주를 정지한 상태에서는 추론 완료가 재생을 다시 시작하지 않습니다.

## 검증

`npm test`는 코사인 계산, 약한 유사도 거절, 감정 투영, 사전 우선권, 부정 표현, 반복/유사 연결 한도, 음악 코드 변화, 오래된 Worker 결과 폐기를 검증합니다. 실제 모델 다운로드·WASM 실행은 브라우저에서 별도로 확인해야 합니다.
